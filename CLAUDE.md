# Consignes pour ce dépôt

Ce dépôt sert aussi de portfolio : tout ce qui est réalisé ici doit être conservé.

## À la fin de chaque projet ou livraison

1. Ranger les livrables finaux (PDF, PNG, MP4, HTML) dans le dossier du projet, avec un `LISEZMOI.md` qui résume le brief, ce qui a été fait et où sont les fichiers.
2. Ajouter ou mettre à jour la fiche du projet dans `PORTFOLIO.md` à la racine : date, projet, type, brief, ce qui a été fait, liens vers les livrables. Garder le tableau du haut trié du plus récent au plus ancien.
3. Faire un commit, puis l'envoyer sur GitHub (`git push`) : la session tourne dans un espace temporaire, ce qui n'est pas poussé est perdu.

Les fichiers `.zip` sont exclus du dépôt : mettre leur contenu dans le dossier du projet, pas le zip lui-même.
